## المرحلة 1: الميزات القاتلة (الأسبوع 1) ★★★

هذه هي المرحلة **الأهم في المشروع كله**. لو نفّذت هذه فقط وتوقفت، سيكون لديك منتج حقيقي.

### 1.1 المشاركة بالرابط — بدون سيرفر 🔗

**الأولوية المطلقة.** بدونها لا يوجد نمو، لأن كل رابط مشاركة = إعلان مجاني.

**التقنية**: ضغط الكود بـ LZ-String ووضعه في **hash الرابط** (`#`). الجزء بعد `#` **لا يُرسل للسيرفر أبدًا** — فتظل الخصوصية سليمة.

```js
// المشاركة
const state = { h: htmlCode, c: cssCode, j: jsCode };
const hash = LZString.compressToEncodedURIComponent(JSON.stringify(state));
const url = `${location.origin}/editor.html#${hash}`;

// الاستعادة عند الفتح
if (location.hash.length > 1) {
  const data = JSON.parse(LZString.decompressFromEncodedURIComponent(location.hash.slice(1)));
  loadState(data);
}
```

**المميزات**:
- ✅ صفر تكلفة (لا سيرفر، لا DB)
- ✅ الروابط لا تنتهي أبدًا (لا اعتماد على خدمة)
- ✅ خصوصية كاملة — تدعم شعارك التسويقي
- ✅ يعمل حتى لو الموقع مفتوح أوفلاين

**الحد**: روابط ~2000 حرف مضغوط تكفي 90% من الحالات. للأكواد الأكبر: زر "تنزيل كملف".

### 1.2 معاينة مباشرة مجاورة + Console

استبدل المعاينة بشاشة كاملة بـ:
- تبويبات **HTML | CSS | JS** (كما CodePen)
- معاينة مجاورة تتحدّث **بعد 400ms** من آخر ضغطة (debounce)
- Console داخلي يعترض `console.log/error/warn` من الـ iframe عبر `postMessage`

```js
// اعتراض console داخل iframe المعاينة
const consoleShim = `<script>
['log','warn','error','info'].forEach(m => {
  const orig = console[m];
  console[m] = (...a) => {
    parent.postMessage({__cz:1, type:m, args:a.map(String)}, '*');
    orig.apply(console, a);
  };
});
window.onerror = (m,s,l) => parent.postMessage({__cz:1,type:'error',args:[m+' :'+l]}, '*');
</script>`;
```

هذا يحوّل الموقع من "محرر نصوص" إلى **playground حقيقي** — وهو ما يبحث عنه الناس فعلًا.

### 1.3 التعريب الكامل + RTL 🇪🇬

**أكبر فرصة في المشروع** — لا يوجد منافس عربي واحد.

- ملف `i18n.js` بكائنين: `ar` و `en`
- `dir="rtl"` على الواجهة (لكن المحرر يبقى LTR — مهم!)
- **الافتراضي عربي** إذا كانت لغة المتصفح عربية
- خط عربي جيد (Cairo / IBM Plex Sans Arabic من Google Fonts — مجاني)
- التبديل يُحفَظ في localStorage

```js
const I18N = {
  ar: { newFile:'ملف جديد', share:'مشاركة', preview:'معاينة', run:'تشغيل', ... },
  en: { newFile:'New File', share:'Share', preview:'Preview', run:'Run', ... }
};
```

### 1.4 PWA — العمل أوفلاين

ميزة **لا يملكها أي منافس**، وتكلفتها ملف واحد.

```json
{
  "name": "CodeZest — محرر أكواد",
  "short_name": "CodeZest",
  "start_url": "/editor.html",
  "display": "standalone",
  "background_color": "#111827",
  "theme_color": "#8b5cf6",
  "lang": "ar",
  "dir": "rtl",
  "icons": [{"src":"/assets/icon-192.png","sizes":"192x192","type":"image/png"},
            {"src":"/assets/icon-512.png","sizes":"512x512","type":"image/png"}]
}
```

**الرسالة التسويقية**: *"ثبّته على هاتفك — يعمل في الطائرة، في المترو، بلا إنترنت."*

```toml
# netlify.toml
[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "SAMEORIGIN"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "strict-origin-when-cross-origin"
    Permissions-Policy = "geolocation=(), camera=(), microphone=()"

[[headers]]
  for = "/sw.js"
  [headers.values]
    Cache-Control = "public, max-age=0, must-revalidate"

[[headers]]
  for = "/assets/*"
  [headers.values]
    Cache-Control = "public, max-age=31536000, immutable"
```

**الهدف الرقمي**: من **12.38 ثانية** → **أقل من 1.5 ثانية**، ومن 20 طلب → 4 طلبات.

## 🎯 مبادئ حاكمة (لا تخالفها)

1. **صفر تكلفة تشغيل دائمًا** — أي ميزة تحتاج سيرفرًا = مرفوضة
2. **الخصوصية هي هويتك** — لا ترسل كود المستخدم لأي مكان أبدًا
3. **الخفة سلاحك** — إذا زادت صفحة عن 300KB، احذف شيئًا
4. **العربية ميزتك الحصرية** — لا تجعلها ترجمة ثانوية
5. **لا تنافس StackBlitz** — لن تفعل npm ولا Node، وهذا **قرار استراتيجي** لا نقص
6. **أطلق ناقصًا** — المرحلة 1 كافية للإطلاق. الكمال عدو الشحن
7. **راقب الفاتورة** — تنبيهات Netlify، وفكّر في Cloudflare Pages (باندويث غير محدود)
