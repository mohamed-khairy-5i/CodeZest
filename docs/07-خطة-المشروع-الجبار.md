# خطة «المشروع الجبار» — بتكلفة صفر

## المبدأ الحاكم

> أي ميزة تُزيد التكلفة مع زيادة عدد المستخدمين = **مرفوضة**.
> أي ميزة تعمل في متصفح المستخدم = **مقبولة**.

هذا المبدأ هو ما يسمح للمشروع بالمنافسة وهو لا يملك جنيهًا واحدًا.

---

## المرحلة 1 — مساعد AI بدون مفتاح ✅ منجزة

```
                 ┌──────────────────────────┐
   المستخدم ───► │  لوحة AI (تُحمَّل عند الطلب) │
                 └────────────┬─────────────┘
                              │  detect()
              ┌───────────────┼────────────────┐
              ▼               ▼                ▼
     ┌────────────────┐ ┌──────────┐ ┌──────────────────┐
     │ Gemini Nano    │ │ Gemini   │ │ OpenAI-compatible│
     │ على الجهاز      │ │ (مفتاحك) │ │ (مفتاحك)         │
     │ صفر شبكة/تكلفة │ │          │ │ OpenRouter/Groq  │
     └────────────────┘ └──────────┘ └──────────────────┘
```

**الإجراءات بلمسة واحدة**

| الإجراء | الغرض |
|---|---|
| اشرح | فهم كود غير مفهوم |
| أصلح | تسمية الخطأ ثم تصحيحه |
| حسّن | القراءة والأداء والتسمية |
| وثّق | تعليقات على الأجزاء غير الواضحة |
| اختبر | اختبارات وحدة مع الحالات الحدية |
| الوصولية | مراجعة a11y |

**قرارات الأمن:** `textContent` فقط · المفتاح في ترويسة لا query string · المفتاح لا يخرج في رابط المشاركة · ملف المستخدم = سياق لا أوامر.

**الأثر على نتليفاي: صفر.** لا يمر أي طلب استدلال عبر استضافتنا.

## المرحلة 2 — Python حقيقي في المتصفح ✅ منجزة

- Pyodide **314.0.3** مثبّت، يُحمَّل من jsDelivr (لا من نتليفاي).
- داخل **Web Worker** مع `terminate()` لقتل الحلقات اللانهائية.
- **تثبيت تلقائي للحزم** من عبارات `import`.
- **بوابة موافقة** تُظهر الحجم (~12 ميجابايت) بالأرقام قبل أي تنزيل.
- زر التشغيل يظهر **فقط** لملفات Python.

**الأثر على نتليفاي: صفر.**

## المرحلة 3 — قابلية الاكتشاف بواسطة الوكلاء ✅ منجزة

`llms.txt` — معيار صاعد يجعل وكلاء AI قادرين على فهم المشروع والتوصية به. في عصر يبحث فيه الناس عبر مساعد لا عبر محرك بحث، هذا قناة توزيع مجانية.

## المرحلة 4 — طبقة التوزيع والانتشار ✅ منجزة

انظر التفصيل الكامل في `docs/08-خطة-الانتشار.md`. الملخص:

| البند | الأثر | الحالة |
|---|---|---|
| صورة مشاركة حقيقية (PNG) | إصلاح 100% من المشاركات المعطوبة | ✅ |
| وضع التضمين `/embed` | محرك النمو الأساسي + روابط خارجية دائمة | ✅ |
| مركز مشاركة (واتساب/تلجرام/X/…) | يصل للقنوات المهيمنة عربيًا | ✅ |
| زر مشاركة النظام `navigator.share` | أعلى سطح نيّة على الهاتف | ✅ |
| رمز QR محلي | حلقة الفصل الدراسي، ولا يسرّب الكود لطرف ثالث | ✅ |
| hreflang + دعم `?lang=` | حضور في نتائج البحث العربية | ✅ |
| تثبيت التطبيق (PWA) | زيارات متكررة بصفر نطاق ترددي | ✅ |

**الإثبات، لا الوعد:** مُرمِّز QR المكتوب من الصفر تم فكّه بنجاح **175/175**
بواسطة `zxing-cpp` — وهي السلالة التي تُبنى عليها ماسحات الهواتف الحقيقية —
على مدى يغطّي **الإصدارات ١ إلى ٤٠ كاملة**، وبنفس نتيجة المكتبة المرجعية
`segno 1.6.6` على نفس المدخلات (175/175 كذلك).

وأقوى من ذلك: اختبار شامل في متصفح حقيقي يفتح لوحة المشاركة، يسحب **البكسلات
التي رسمها المتصفح فعلاً** من `canvas` عبر `toDataURL`، ثم يفكّها بـ ZXing
ويقارنها بالرابط الأصلي — فتطابقت **بايت ببايت** (١٠٧٤ بايت). هذا الاختبار هو
نفسه الذي كشف خللاً حقيقياً في سقف السعة وأدّى إلى تصحيحه؛ التفصيل الكامل
(وسبب رفض OpenCV كحكم) في `docs/08`.

## المرحلة 5 — مرآة استضافة مجانية

مرآة على **Cloudflare Pages** (نطاق ترددي غير محدود). الكود محمول 100%، فالترحيل دقائق.

---

## خارج النطاق (ولماذا)

| مرفوض | السبب |
|---|---|
| حساب مستخدم وقاعدة بيانات | تكلفة تنمو مع النجاح |
| Netlify Functions / Edge | بند الحوسبة = تجميد الموقع |
| مفتاح AI مملوك للتطبيق | يكلّف مالًا ويُسرق |
| WebLLM كافتراضي | يخون باقة البيانات المحدودة |
| Node في المتصفح | يحتاج ترويسات تكسر التضمين |

## مقاييس النجاح

| المقياس | الهدف |
|---|---|
| حجم أول زيارة | < 60 كيلوبايت |
| تكلفة الاستدلال | صفر دائمًا |
| نسبة أرصدة نتليفاي المستهلكة | < 50% شهريًا |
| المشاركات التي تُعرض بصورة | 100% |
| المواقع التي تضمّن المحرّر | > 0 (كان مستحيلًا تقنيًا) |
