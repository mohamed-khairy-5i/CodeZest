## 1. ما هو المشروع فعليًا؟

**CodeZest Pro** هو محرر أكواد أونلاين مبني بالكامل في ملف HTML واحد، يعمل 100% على المتصفح (client-side) بدون أي سيرفر أو قاعدة بيانات.

### الهيكل التقني

| العنصر | التفصيل |
|---|---|
| المعمارية | ملف HTML واحد، Vanilla JS، بدون build step |
| المحرر | CodeMirror 5.65.2 (من CDN) |
| التنسيق | Tailwind CSS عبر `cdn.tailwindcss.com` (نسخة التطوير!) |
| الأيقونات | Font Awesome 6.4.0 (CDN) |
| التخزين | `localStorage` بمفتاح `codezest_files` — حد 10 MB |
| المكتبات | `js-beautify`، `JSZip`، `pako`، `html2canvas` |
| الاستضافة | GitHub Pages حاليًا (كان هناك CNAME متغيّر عدة مرات) |
| اللغة | إنجليزي فقط، `dir="ltr"` |

### الميزات الموجودة فعلًا

1. **إدارة ملفات**: إنشاء / فتح / حذف / رفع ملفات (22 امتداد مدعوم في القائمة)
2. **محرر**: أرقام أسطر، إغلاق تلقائي للأقواس والوسوم، بحث واستبدال، Undo/Redo
3. **تنسيق الكود**: Format / Minify / Beautify
4. **ضغط الملفات**: ZIP عبر JSZip مع شريط تقدّم ونسبة الضغط
5. **معاينة**: iframe بشاشة كاملة لملفات HTML
6. **Screenshot**: التقاط صورة للمعاينة عبر html2canvas
7. **ثيمات**: Monokai / Dracula / Material / Default + Dark Mode
8. **موبايل**: Swipe لفتح الـ sidebar، منع double-tap zoom
9. **اختصارات**: Ctrl+S/O/N/B/P/F/H
10. **تحسينات أداء**: debounce، `requestAnimationFrame`، تقليل `viewportMargin` للملفات الكبيرة

## 5. الحكم النهائي

المشروع **ليس فاشلًا** — بل هو **أساس صحيح بُني عليه قرارات خاطئة**.

الأصول الحقيقية التي يملكها:
1. معمارية static = تكلفة صفر للأبد (وهذا يناسب وضعك المالي تمامًا)
2. الخصوصية الكاملة (client-side) = ميزة تنافسية لم تُستغل
3. لا تسجيل دخول = أقل احتكاك في السوق

المشكلة أن المشروع حاليًا يحاول تقليد CodePen **وهو أسوأ منه في كل شيء**. الحل ليس المنافسة المباشرة، بل **إعادة تحديد ساحة المعركة** — وهذا موضوع المستندين التاليين.
