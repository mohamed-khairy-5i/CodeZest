# CodeZest v2.0 🚀

Online code editor playground — **Monaco Editor** (محرك VS Code) في المتصفح.

### Features
- ✏️ **3 أجزاء** HTML/CSS/JS مع Monaco Editor
- 👁️ **Live Preview** مباشر
- 🖥️ **Console** للمخرجات
- 🌙 **Dark/Light** mode
- 📥 **Export** كملف HTML
- 🚀 **Deploy** بنقرة واحدة
- 📱 **PWA** تشتغل أوفلاين
- 🧠 **AI Suggestions** (قريباً)

### Tech Stack
Vite 7 + React 19 + TypeScript 6 + Monaco Editor + Tailwind v4 + PWA

### Dev
```bash
pnpm install
pnpm dev
```

### Build
```bash
pnpm build  # → dist/
```
